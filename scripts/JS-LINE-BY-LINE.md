# JavaScript: построчные пояснения (`scripts/`)

Формат: **номер строки** — что делает эта строка (или небольшой неразрывный фрагмент). Длинные повторяющиеся куски (объекты товаров, HTML в шаблонной строке) сгруппированы с указанием диапазона.

Общие приёмы:

- **`(function () { … })();`** — IIFE: код выполняется сразу, не засоряя глобальные имена (кроме явно назначенных `window.*`).
- **`?.`** — optional chaining: если слева `null`/`undefined`, обращение не падает, результат `undefined`.
- **`??`** — nullish coalescing: подставить правую часть, только если слева `null` или `undefined`.

## Объект `window.BuildmartCart` (методы как «API»)

Вызывается из других файлов; реализация в `cart-store.js` (см. таблицу выше).

| Метод | Назначение |
|--------|------------|
| `read()` | Текущий массив `{ id, qty }`. |
| `add(id, qty)` | Добавить или увеличить количество. |
| `setQty(id, qty)` | Задать количество для существующей строки. |
| `remove(id)` | Удалить строку. |
| `clear()` | Очистить корзину. |
| `countLines()` | Число позиций. |
| `countItems()` | Сумма количеств (для бейджа). |
