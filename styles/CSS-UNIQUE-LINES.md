# Уникальные строки в CSS проекта: что означает каждая **категория**

В папке `styles/` после удаления пустых строк и дубликатов получается порядка **1000+ уникальных строк**. Большинство из них — это либо **селектор** с открывающей `{`, либо **`свойство: значение;`**, где меняется только число или цвет. Ниже:

1. Как читать **любую** строку в `.css`.
2. Каждое **уникальное имя свойства** (их ровно **92** в этом проекте) — отдельное пояснение.
3. Уникальные **`@media`**, **`@keyframes`**, вендорные и служебные строки.
4. Как понимать **уникальные селекторы** и **уникальные значения** без перечисления каждого пикселя.

Полный дамп уникальных строк можно снова получить скриптом; в репозитории он не хранится.

---

## 1. Типы строк в CSS-файле

| Уникальная строка (пример) | Что делает |
|----------------------------|------------|
| `.block__element {` | **Селектор + открывающая скобка** — начало правила для класса `block__element`. Дальше идут объявления до `}`. |
| `@media (min-width: 768px) {` | **Условный блок** — вложенные правила применяются только если условие истинно (здесь: ширина области просмотра ≥ 768px). |
| `@keyframes cart-page-promo-hint-in {` | **Имя анимации** — дальше кадры `from { … }` / `to { … }` задают, какие свойства и как меняются во времени. |
| `  color: #101828;` | **Объявление**: свойство `color` задаёт цвет текста, значение `#101828` — тёмно-серый из палитры. |
| `}` | **Закрывающая скобка** — конец блока правил или конец `@media` / `@keyframes`. |
| `/* … */` | **Комментарий** — для разработчика, браузер не использует. |
| `  transition:` и следующая строка без `;` | **Многострочное значение** — одно свойство `transition` продолжается на следующей строке до `;`. |
| `  box-shadow:` и строки с тенью | То же: одно свойство на несколько строк. |

Строки вроде `0 10px 40px rgba(15, 23, 42, 0.12),` — это **продолжение** `box-shadow`, не отдельное правило; смысл: второй слой тени.

## 2. Все **92 уникальных имени свойства** в проекте — что делает каждое

| Свойство | Назначение |
|----------|------------|
| `align-items` | Выравнивание дочерних элементов **по поперечной оси** во flex- или grid-контейнере (`center`, `flex-start`, `stretch` …). |
| `align-self` | То же, но **для одного** элемента внутри flex/grid, переопределяя `align-items`. |
| `animation` | Подключение именованной `@keyframes`-анимации: имя, длительность, easing. |
| `appearance` | Сброс нативного оформления контролов; `none` — чтобы стилизовать свой вид (например слайдер). |
| `aspect-ratio` | Фиксированное соотношение сторон блока (`1` = квадрат, `4 / 3` и т.д.). |
| `background` | Сокращение для фона: цвет, градиент или картинка в одной строке. |
| `background-color` | Цвет заливки фона под контентом. |
| `background-image` | Картинка или градиент фона; у вас есть `url(data:…)` для стрелки в `<select>`. |
| `background-position` | Где расположен фон относительно блока (`right 12px center` и т.п.). |
| `background-repeat` | Повтор фоновой картинки (`no-repeat`). |
| `border` | Сокращение: толщина, стиль и цвет **всех** границ сразу. |
| `border-bottom` | Только нижняя граница. |
| `border-bottom-color` | Цвет нижней границы (часто с `var(--line, …)`). |
| `border-color` | Цвет линии границы для текущего `border`. |
| `border-radius` | Скругление углов (`8px`, `50%` = круг/капсула). |
| `border-right` | Правая граница (у вас иногда `0` — убрать линию). |
| `border-top` | Верхняя граница. |
| `bottom` | Отступ от **нижнего** края родителя с `position: relative/absolute/fixed`. |
| `box-shadow` | Тень вокруг блока: смещение, размытие, цвет; может быть несколько теней через запятую. |
| `box-sizing` | `border-box` — ширина/высота **включают** padding и border (удобно для вёрстки). |
| `--buildmart-toast-overlap` | **Кастомное свойство**: вертикальное перекрытие карточек тостов; задаётся из JS по высоте. |
| `--card-gallery-width` | **Кастомное свойство**: ширина галереи на карточке товара (`100%` или `min(584px, 100%)` на десктопе). |
| `clip` | `rect(0,0,0,0)` — классический трюк «спрятать визуально, оставить для скринридеров» (`.footer__visually-hidden`). |
| `color` | Цвет **текста** и часто наследуемый цвет иконок (`currentColor`). |
| `column-gap` | Расстояние между **колонками** в grid/flex (горизонтальный зазор). |
| `content` | Текст или пустая строка для **псевдоэлементов** `::before`/`::after`; у вас подписи «Price:», «Total:». |
| `cursor` | Вид указателя: `pointer` — как ссылка, `default`, `grab`/`grabbing` — «рука». |
| `display` | Модель отображения: `block`, `flex`, `grid`, `none` (скрыть), `inline-flex` и т.д. |
| `fill` | Заливка **SVG** (`none` — только обводка). |
| `filter` | Визуальный фильтр (`brightness(0.96)` — чуть затемнить). |
| `flex` | Сокращение `flex-grow`, `flex-shrink`, `flex-basis` — как элемент **растёт/сжимается** в flex-ряду. |
| `flex-direction` | Направление главной оси: `row` (в ряд) или `column` (в столбик). |
| `flex-shrink` | Может ли flex-элемент сжиматься при нехватке места (`0` = не сжимать). |
| `flex-wrap` | Перенос flex-элементов на новую строку (`wrap` / `nowrap`). |
| `font-family` | Шрифт и запасные варианты (`Inter`, `system-ui` …). |
| `font-size` | Размер шрифта (`px`, `rem`, `clamp(…)` для адаптива). |
| `font-style` | `normal` / `italic`. |
| `font-weight` | Насыщенность (`400` обычный, `700` жирный, `800` и т.д.). |
| `gap` | Зазор между **и** строками **и** колонками в grid/flex (современная замена margin-хакам). |
| `grid-column` | На каких линиях сетки занимает ячейка (`1 / -1` = на всю ширину). |
| `grid-template-columns` | Шаблон колонок grid: доли `1fr`, `minmax`, `repeat(3, 1fr)` и т.д. |
| `height` | Высота блока (`auto`, `100%`, конкретные `px` из макета). |
| `justify-content` | Выравнивание по **главной оси** flex/grid (`space-between`, `center` …). |
| `justify-self` | Выравнивание **одной** ячейки внутри grid по главной оси. |
| `left` | Отступ от **левого** края при позиционировании; в процентах — для слайдера/заливки диапазона. |
| `letter-spacing` | Межбуквенный интервал (в `em` или `px`). |
| `line-height` | Высота строки текста (множитель или `px`). |
| `list-style` | Маркеры списка (`none` — убрать точки у `<ul>`). |
| `margin` | Внешние отступы со всех сторон или сокращённая запись `10px 0`. |
| `margin-bottom` | Отступ снизу снаружи блока. |
| `margin-inline` | Логические отступы слева+справа (`auto` — центрирование блока). |
| `margin-left` / `margin-right` / `margin-top` | Отступы с одной стороны; `auto` часто раздвигает flex-элементы. |
| `max-height` | Максимальная высота (`0` для свёрнутого аккордеона, `none` — без ограничения). |
| `max-width` | Максимальная ширина (`1280px` контейнер, `100%` не вылезти за родителя). |
| `min-height` | Минимальная высота (чтобы блок не схлопнулся, `100vh` на всю высоту экрана). |
| `min-width` | Минимальная ширина; `0` в grid/flex — разрешить сжатие текста без переполнения. |
| `object-fit` | Как **картинка** заполняет `<img>`: `cover` — обрезать с сохранением пропорций. |
| `opacity` | Прозрачность (`0` невидим, `1` непрозрачен). |
| `outline` | Рамка фокуса вокруг элемента (доступность, не влияет на размер как border). |
| `outline-offset` | Зазор между элементом и outline. |
| `overflow` | Что делать с переполнением: `hidden` обрезает, `auto` даёт прокрутку, `visible` не режет. |
| `padding` | Внутренние отступы от края блока до контента. |
| `padding-bottom` / `padding-top` / `padding-right` | Padding с одной стороны. |
| `padding-inline` | Padding слева и справа (логические стороны). |
| `pointer-events` | `none` — клики «проходят сквозь» (стек тостов), `auto` — обычные клики. |
| `position` | Схема позиционирования: `static` обычный поток, `relative` со смещением, `absolute` внутри relative, `fixed` к окну, `sticky` — «прилипание» при скролле. |
| `right` | Отступ от правого края при позиционировании; у тостов — с учётом safe-area. |
| `row-gap` | Зазор между **рядами** в grid/flex. |
| `stroke` | Цвет **обводки SVG** (`currentColor` — как текст). |
| `stroke-linecap` / `stroke-linejoin` | Форма концов и стыков линии SVG. |
| `stroke-width` | Толщина линии SVG. |
| `text-align` | Выравнивание текста (`left`, `center`, `right`). |
| `text-decoration` | Подчёркивание и т.п.; `none` у ссылок без линии. |
| `text-overflow` | `ellipsis` — многоточие при обрезке длинного текста (с `overflow` + `white-space`). |
| `text-transform` | Регистр букв (`uppercase`). |
| `top` | Отступ от верхнего края при позиционировании; `50%` + `transform` — вертикальное центрирование. |
| `touch-action` | Как браузер обрабатывает касания: `pan-y` вертикальный скролл, `none` для свайпа тоста. |
| `transform` | Сдвиг, масштаб, поворот (`translateY`, `scale`, `rotate`). |
| `transition` | Плавная смена свойств во времени при наведении/открытии. |
| `user-select` | Можно ли выделять текст (`none` на кнопках). |
| `-webkit-appearance` | Вендорный сброс вида контролов в WebKit/Blink. |
| `-webkit-overflow-scrolling` | Плавный скролл на старых iOS. |
| `-webkit-tap-highlight-color` | Цвет вспышки при тапе на iOS (`transparent` — убрать). |
| `-webkit-user-select` | Вендорный вариант `user-select`. |
| `white-space` | Перенос строк: `nowrap` одна строка, `normal` обычный перенос. |
| `width` | Ширина блока (`100%`, `min(400px, …)`, фиксированные `px` из макета каталога). |
| `z-index` | Порядок **наслоения** по оси Z (больше — «ближе к зрителю»). |

## 3. Уникальные строки `@media` и `@keyframes`

| Строка | Смысл |
|--------|--------|
| `@media (max-width: 425px) {` | Очень узкие телефоны. |
| `@media (max-width: 767px) {` | Телефоны и малые экраны до 767px. |
| `@media (max-width: 1023px) {` | Всё, что уже не «широкий десктоп». |
| `@media (min-width: 640px) {` | От планшета и шире — чуть больше отступы контейнера. |
| `@media (min-width: 768px) {` | Планшетный/десктопный хедер, сетки. |
| `@media (min-width: 768px) and (max-width: 768px) {` | Ровно одна ширина 768px (тонкая подгонка корзины). |
| `@media (min-width: 768px) and (max-width: 1023px) {` | Диапазон планшета. |
| `@media (min-width: 1024px) {` | Десктоп: две колонки на карточке товара и т.д. |
| `@media (min-width: 1024px) and (max-width: 1024px) {` / `1279px` / `(width: 1024px)` | Точечные правки под конкретные ширины макета/корзины. |
| `@media (min-width: 1440px) {` | Широкие мониторы — сетка хедера с `max-content` для поиска. |
| `@keyframes cart-page-promo-hint-in {` | Имя анимации подсказки промокода. |
| `from {` / `to {` | Начальный и конечный кадр анимации (обычно `opacity` / `transform`). |

## 4. Уникальные **селекторы** (сотни строк вида `.catalog__… {`)

Они не «делают действие» сами по себе — они **выбирают узлы в HTML**. Паттерн именования:

- **`block__element`** — элемент внутри блока (БЭМ).
- **`block__element--modifier`** — вариант (например кнопка первичная `--primary`).
- **`,`** в одной строке — несколько селекторов с **одинаковыми** стилями.
- **`A B`** — элемент `B` внутри `A`.
- **`A:hover`**, **`:focus-visible`**, **`[hidden]`**, **`[aria-checked="true"]`** — состояние или атриут.

Имеет смысл смотреть селектор **вместе со следующими строками** до `}`: там перечислено, что именно меняется (отступы, цвет, grid и т.д.) через таблицу свойств выше.

## 5. Уникальные строки **значений** (`width: 1216px`, `gap: 8px`, …)

Таких сотни. Общий принцип:

| Вид строки | Смысл |
|--------------|--------|
| `width: 1216px;` / `height: 72px;` | Фиксированные размеры из **макета каталога** (сетка 1216px и блоки шапки секции). |
| `width: min(400px, calc(100vw - 32px));` | Не шире 400px и не шире экрана минус отступы — **тосты**. |
| `clamp(14px, 2.4vw, 24px)` | Отступ/gap **плавно растёт** с шириной окна между минимумом и максимумом. |
| `color: #f54900` и похожие | **Акцентный оранжевый** бренда; серые `#4b5563`, `#101828` — текст и заголовки. |
| `var(--line, #e4e7ec)` | Использовать переменную `--line`, а если её нет — цвет `#e4e7ec`. |
| `display: none !important;` | Принудительно скрыть (перебить другие правила) — важно для `[hidden]` рядом с flex. |

Каждое новое **число** в `width`/`height`/`top`/`left` — это не новое «волшебство CSS», а другой размер блока в той же системе координат.

## 7. Ключевые слова значений: что значит `center`, `flex-start`, `stretch` и похожие

Ниже — **не имена свойств**, а **варианты значений**, которые чаще всего сбивают с толку. Они задают **поведение раскладки** или отображения.

### `align-items` (поперечная ось во flex / grid)

Родитель выравнивает **всех детей** по линии, перпендикулярной «главному» направлению (при `flex-direction: row` поперечная ось — **вертикаль**).

| Значение | Что делает |
|----------|------------|
| `stretch` | Дети **растягиваются** на всю высоту (или ширину) ряда — типично по умолчанию во flex. |
| `flex-start` | Прижать к **началу** поперечной оси (для `row` в LTR — к **верху** ряда). |
| `flex-end` | Прижать к **концу** поперечной оси (внизу ряда при `row`). |
| `center` | **По центру** поперечной оси. |
| `baseline` | Выровнять по **базовой линии текста** — полезно, когда в ряду и текст, и иконки. |
| `start` / `end` | Логические аналоги начала/конца оси (учёт RTL и writing-mode); в простом LTR часто совпадают с `flex-start` / `flex-end`. |

### `justify-content` (главная ось во flex / иногда распределение в grid)

| Значение | Что делает |
|----------|------------|
| `flex-start` | Все элементы **с начала** главной оси (слева при `row` и LTR), **без** растягивания промежутков между ними. |
| `flex-end` | Сжать группу к **концу** главной оси (вправо). |
| `center` | Группа целиком **по центру** главной оси. |
| `space-between` | Первый у края, последний у края, **равные зазоры между** соседними (крайние без отступа от края). |
| `space-around` | У каждого элемента **половинный** зазор слева и справа — на краях остаётся узкая «половинка». |
| `space-evenly` | Все промежутки **одинаковые**, включая от края до первого элемента. |
| `normal` | Значение по умолчанию для контекста (часто как `flex-start` во flex). |

### `align-self` (один ребёнок, не вся строка)

Те же идеи, что у `align-items`, но **только для одного** элемента; перебивает `align-items` родителя.

### `justify-self` (одна ячейка в CSS Grid)

| Значение | Что делает |
|----------|------------|
| `auto` | Как решит grid и содержимое. |
| `start` / `end` | Прижать содержимое ячейки к началу/концу **вдоль строки** сетки. |
| `center` | По центру ячейки. |
| `stretch` | Растянуть по ячейке (если само содержимое это позволяет). |

### `flex-direction`

| Значение | Что делает |
|----------|------------|
| `row` | Главная ось **горизонтально** (слева направо в LTR). |
| `column` | Главная ось **вертикально** (сверху вниз). |
| `row-reverse` / `column-reverse` | То же, но порядок детей **обратный**; «начало» оси меняется местами с «концом». |

### `flex-wrap`

| Значение | Что делает |
|----------|------------|
| `nowrap` | Все в **одну линию** (могут сжаться или вылезти). |
| `wrap` | Не помещаются — **перенос на новую строку** (или колонку при `column`). |
| `wrap-reverse` | Перенос, но новые линии идут **в обратном визуальном порядке**. |

### `object-fit` (картинка в `<img>` / `video`)

| Значение | Что делает |
|----------|------------|
| `fill` | Растянуть в рамку, **пропорции могут сломаться**. |
| `contain` | Вписать целиком, **поля** могут остаться пустыми. |
| `cover` | Заполнить рамку, **обрезая** лишнее; пропорции сохранены (у вас часто так). |
| `none` | Не масштабировать под рамку автоматически. |
| `scale-down` | Как `none` или `contain` — что **меньше** по размеру. |

### `position`

| Значение | Что делает |
|----------|------------|
| `static` | Обычный поток документа; `top`/`left` не действуют. |
| `relative` | Место в потоке как у `static`, но можно **сдвинуть** относительно себя (`top` и т.д.). |
| `absolute` | Выпадает из потока; позиция от **ближайшего позиционированного предка** (`relative`/`absolute`/…). |
| `fixed` | Относительно **окна** браузера; при скролле «прилипает» к экрану. |
| `sticky` | В потоке, но при скролле **прилипает** к `top`/`bottom`, пока не кончится родитель. |

### `display` (часто встречающиеся)

| Значение | Что делает |
|----------|------------|
| `block` | Блок на всю ширину родителя (с переносом строки до/после). |
| `inline` | В строке с текстом, размеры от содержимого. |
| `inline-block` | В строке, но можно задать `width`/`height`. |
| `flex` | Flex-контейнер; дети — flex-элементы (`align-items`, `justify-content` и т.д.). |
| `grid` | Сетка; колонки/ряды через `grid-template-columns` и т.п. |
| `none` | Элемент **не рисуется** и не занимает место (как скрытый). |

### `overflow`

| Значение | Что делает |
|----------|------------|
| `visible` | Переполнение **видно** (может вылезать за границы). |
| `hidden` | **Обрезать** всё, что выходит за рамку. |
| `scroll` | Всегда показывать полосы прокрутки (если браузер не упрощает). |
| `auto` | Полосы **только если** нужно прокручивать. |

### `white-space`

| Значение | Что делает |
|----------|------------|
| `normal` | Перенос строк как обычно. |
| `nowrap` | **Не переносить** текст и inline-блоки — одна линия (часто с `text-overflow: ellipsis`). |

### `text-align`

| Значение | Что делает |
|----------|------------|
| `left` / `right` | Выравнивание текста и inline-содержимого. |
| `center` | По центру **внутри строки**. |
| `justify` | Растянуть пробелы между словами под ширину строки. |

### `cursor`

| Значение | Что делает |
|----------|------------|
| `default` | Обычная стрелка. |
| `pointer` | «Рука» — как над ссылкой или кнопкой. |
| `grab` / `grabbing` | «Рука схватила» — для перетаскиваемых областей. |
| `text` | I‑образный курсор над текстом. |

### `pointer-events`

| Значение | Что делает |
|----------|------------|
| `auto` | Обычные клики и наведение. |
| `none` | События мыши/тача **проходят сквозь** элемент к тому, что под ним. |

### `box-sizing`

| Значение | Что делает |
|----------|------------|
| `content-box` | `width`/`height` — только **контент**; padding и border добавляются снаружи. |
| `border-box` | `width`/`height` — **вся коробка** включая padding и border (удобно для вёрстки). |

### `text-overflow`

| Значение | Что делает |
|----------|------------|
| `clip` | Обрезать текст без многоточия. |
| `ellipsis` | В конце обрезанной строки **`…`** (нужны обычно `overflow: hidden` и `white-space: nowrap`). |

---

Если нужен именно **машинный список всех 1000+ уникальных строк** с автоматическим коротким комментарием к каждой — его лучше генерировать скриптом в CI или локально; вручную поддерживать синхронно с CSS нецелесообразно.
